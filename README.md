# Rodeo FC

Team management app for the coaching staff of a women's fútbol 7 team, replacing a disorganized WhatsApp group with a centralized platform for training, tactics, and match scheduling.

## Live
[rodeofc.vercel.app](#) <!-- reemplazar con tu URL real -->

## Features
- Player management (roster CRUD, unique squad numbers)
- Interactive tactical board with animated play-by-play
- Training/exercise library organized by category
- Opponent scouting with match history
- Shared calendar for matches and training sessions
- Installable as a PWA on Android and iOS
